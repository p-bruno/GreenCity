# 🌿 GreenCity — Site web de la mairie de Villevert

Bienvenue sur le dépôt officiel du site web de la mairie de **Villevert**. Ce projet a pour but de fournir aux habitants un accès simple et rapide aux informations municipales, aux démarches administratives et aux actualités locales.

## À propos

GreenCity est un site web **open source** développé bénévolement par des habitants de Villevert. Il remplace l'ancien site Flash de la mairie, devenu obsolète et inaccessible sur mobile.

> "Notre objectif est de rendre les services publics accessibles à tous, depuis n'importe quel appareil." — Équipe GreenCity

---

## Fonctionnalités

- Consultation des **actualités** et événements locaux
- Accès aux **démarches administratives** en ligne
- Carte interactive des **équipements municipaux**
- Formulaire de **contact** pour les administrés
- Site entièrement **responsive** et accessible

---

## Installation

Pour lancer le projet en local, suivez ces étapes :

1. Clonez le dépôt
2. Installez les dépendances
3. Lancez le serveur de développement

```bash
git clone https://github.com/villevert/greencity.git
cd greencity
npm install
npm run dev
```

Le site est maintenant accessible sur `http://localhost:3000`.
